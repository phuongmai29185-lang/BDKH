# 🌱 Hành Động Vì Khí Hậu Cà Mau

Website giáo dục nâng cao nhận thức và hành vi ứng phó với biến đổi khí hậu.

## Cấu trúc

- `index.html` — giao diện chính
- `style.css` — màu sắc, bố cục và responsive
- `script.js` — menu, thử thách xanh, quiz, chia sẻ và nút lên đầu trang

## Đăng lên GitHub Pages

1. Tạo một repository mới trên GitHub.
2. Tải 3 file `index.html`, `style.css`, `script.js` lên repository.
3. Vào **Settings → Pages**.
4. Ở **Build and deployment**, chọn **Deploy from a branch**.
5. Chọn branch `main` và thư mục `/ (root)`.
6. Nhấn **Save**.
7. Sau khi GitHub hoàn tất triển khai, mở đường dẫn GitHub Pages được cung cấp.

## Tùy chỉnh

Trong `index.html`, bạn có thể thay:
- Tên website
- Nội dung hoạt động
- Thông tin bên phải
- Email liên hệ
- Các thông điệp và câu hỏi

Trong `style.css`, có thể thay đổi màu sắc tại phần `:root`.
